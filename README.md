# Проект "Муравейник"

Приложение для автоматизации деятельности сотрудников делопроизводства распределённого предприятия (головной офис и филиалы) по учету внутренней корреспонденции.

## Описание

Система предназначена для автоматизации процессов учета приема/передачи внутренней корреспонденции между филиалами предприятия и головным офисом. Приложение позволяет:

- Учитывать документы с присвоением соответсвующих реквизитов (исходящих номеров, дат и др.)
- Формировать пакеты экспорта документов для передачи в из филиала в головной офис
- Импортировать пакеты документы из филиалов
- Формировать пакеты экспорта оценок, выставленных документам для передачи из головного офиса в филиал
- Импортировать оценки документов из головного офиса
- Подсчитывать статистику по отработанным документам и выставленным оценкам, в соответствии с заданными параметрами
- Осуществлять быстрый поиск по реквизитам документов

## Требования

- Python 3.7+
- PyQt5
- peewee
- СУБД - SQLite
